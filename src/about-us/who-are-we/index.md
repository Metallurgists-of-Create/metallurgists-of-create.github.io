# Who Are We?

The Metallurgists of Create are a growing team of developers, artists, and planners who aim to create mods that bring realism to Minecraft in a player-friendly way.

## Our Projects
- Our main project is **Metallurgica**, an in-dev addon for **Create: TFMG 1.21.1** that aims to add realistic ore and mineral processing utilising semi-accurate geology and chemistry.
- **TFMG Community Edition** is our official fork of Create: TFMG by DrMangoTea. It exists to fix bugs and improve the old codebase to be more customisable. It will be merged into the main mod at a later date.
- **Rutile** is a heavy-wip API for chemical compositions and material registry. As of writing this, it only contains chemical compositions.
- **Titanium** is a heavy-wip extension to **Rutile** that will contain utilities for Create-specific material part generation like Cogwheels and Casings.
- **Hematite** is a near-complete API for a changing world. It contains updated and improved code from **Immersive Weathering** tweaked to work on any block, with better datapack customisability and built-in KubeJS integration.
