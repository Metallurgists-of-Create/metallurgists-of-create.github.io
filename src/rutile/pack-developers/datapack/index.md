# Datapack Functionality

For KubeJS, see [KubeJS Integration](/rutile/pack-developers/kubejs) (Not Yet Implemented)

> [!NOTE]
> When creating a datapack, it is good practice to have your own namespace to separate your changes to the changes a mod has made.
> <br> If you are overriding a conditionally loaded file (recipes), create an empty file with the `neoforge:false` condition under the original namespace and add your own file under yours.

Rutile has a few options for datapack customisation.
