# Hematite {#hematite}

Our API for a naturally changing world.

# About

Hematite is a forked and updated version of Immersive Weathering's various systems designed to be compatible with any block and allow for even more datapack customisation.

Hematite supports data driven "block growths" and fluid generators as well as various registries for more complex aspects of weathering.
